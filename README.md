# Sparklet

Sparklet 本地模型工作台的程序发布仓库，用于分发服务端程序、桌面安装包和版本说明。

## 下载

在本仓库的 [Releases](https://github.com/sparklet-si/sparklet/releases) 页面选择版本和适合自己平台的资产。只有列出下载资产的平台才属于该版本的已发布范围。

- **服务端程序包**：解压后运行 `sparklet` / `sparklet.exe`；包含 `sparklet-release.json` 的目录也可由桌面端“服务管理”导入。
- **桌面安装包**：按对应版本说明安装，再安装服务端程序包或连接已有服务。
- **SHA256SUMS**：下载后校验文件完整性；平台依赖、升级步骤和已知问题以该版本说明为准。

模型权重独立下载，不包含在程序包中。第三方组件的授权与声明随程序包提供。

## 版本规则

首次正式版本从 `0.1.0` 开始。后续默认增加第三段，例如 `0.1.1`、`0.1.2`；第二段或第一段仅由维护者明确决定升级。版本 tag 使用 `v0.1.0` 形式，已发布的版本和文件不覆盖。

## 源码

本仓库公开用于程序发布，Sparklet 产品源码目前暂不开放。GitHub 自动提供的 **Source code (zip/tar.gz)** 仅包含本发布仓库的说明文件，并非 Sparklet 产品源码。
